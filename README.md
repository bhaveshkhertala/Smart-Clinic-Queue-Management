# Smart Clinic Queue Management System

A web-based application designed to help patients check clinic queue status and estimated waiting times before visiting a clinic.

## Project Overview

The Smart Clinic Queue Management System helps patients understand clinic crowd levels and queue information. It also provides separate dashboards for patients and doctors.

## Technology Stack

- **Frontend:** React.js
- **Backend:** Java, Spring Boot
- **Database:** MySQL

## Project Features

- Patient Registration and Login
- Patient Dashboard
- Doctor Dashboard
- Clinic Information
- Queue Management
- Estimated Waiting Time
